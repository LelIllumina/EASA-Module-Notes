## Overview

An Aircraft has 3 axes of Rotation. It rotates around these axes which causes its corresponding movement.

## Key Points

 - Lateral Axis
	 - Rotation around this is called Pitching
	 - Is determined using a straight line parallel to the Wingspan
	 - Controlled by the elevators
 - Longitudinal Axis
	 - Rotation around this is called Rolling
	 - Is determined using a straight line from the nose to the tail
	 - Controlled by the Ailerons
 - Vertical Axis
	 - Rotation around this is called Yawing
	 - Is determined using a straight line passing through the CG Vertically
	 - Controlled using the Rudder
 - All 3 Axes pass through the CG and are perpendicular to each other
 - Rotation on these Axes can both be simultaneous or independent (one at a time)
